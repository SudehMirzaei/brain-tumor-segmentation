# Image Segmentation Documentation

Welcome to the Image Segmentation documentation! This repository contains essential resources to understand the different aspects of image segmentation, particularly in the medical domain.

## Overview

Image segmentation is a critical task in computer vision that involves partitioning an image into meaningful regions. It is widely applied in various fields, including medical imaging, where accurate segmentation can significantly impact diagnosis and treatment planning.

## Documentation Files

Here are the key documents included in this repository:

1. [What is Image Segmentation?](what-is-image-segmentation.md)
   - This document provides an overview of image segmentation, its importance, key concepts, methods, and applications.

2. [Semantic vs Instance Segmentation](semantic-vs-instance-segmentation.md)
   - This document distinguishes between semantic segmentation and instance segmentation, explaining their definitions, characteristics, use cases, and challenges.

3. [Medical Image Segmentation](medical-image-segmentation.md)
   - This document discusses the application of segmentation techniques in medical imaging, outlining its importance, common modalities, challenges, and the role of deep learning in this field.
